# iCare

iCare is a youth-led mental health initiative website.

## Preview locally

Open `index.html` in a browser, or open any of the additional pages (`about.html`, `resources.html`, `contact.html`).

## Included

- Multi-page static website for the iCare brand
- Landing page with mental health awareness content
- About, resources, and contact sections
- Instagram links and call-to-action buttons
- Responsive styling for mobile and desktop
